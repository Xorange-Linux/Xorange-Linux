## ⚙️ System Requirements

Designed to run smoothly even on older hardware (built and tested directly on an **Intel Core i3-3217U**):

| Component | Minimum Specification | Notes |
| :--- | :--- | :--- |
| **CPU** | 1 GHz (1 Core) | x86_64 architecture |
| **RAM** | 700 MiB | Ultra-low idle memory footprint |
| **Storage** | 15 GiB | Base Debian Testing installation |

## 📖 About the Project

* **Base System:** Built on **Debian 13 (Testing)** for a solid balance between stability and up-to-date packages.
* **Package Management:** Uses **APT**, giving you instant access to the massive Debian package ecosystem.
* **Display Server:** Originally named "X" after the X11 compositor, with plans to move away from X11 due to memory leaks and legacy limitations.
* **Codename History:** Shifted from *Orange* to *Lemon*—because citrus is citrus.
* **Future Roadmap:** Exploring a **Linux From Scratch (LFS)** build down the road (as soon as our sanity recovers).
