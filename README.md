## ✨ Why Xorange-Linux?

<!-- 2x2 CSS-Style Feature Grid -->
<table>
  <tr>
    <td width="50%" valign="top">
      <h3>⚡ Arch Linux Core</h3>
      <p>Rebuilt from the ground up on <b>Arch Linux</b> after migrating away from Debian. Enjoy rolling-release updates, bleeding-edge packages, and full access to <b>Pacman</b>.</p>
    </td>
    <td width="50%" valign="top">
      <h3>🪶 Built for Old Hardware</h3>
      <p>Compiled and battle-tested directly on an <b>Intel Core i3-3217U</b>. If it runs smoothly on a dual-core 3rd-gen laptop chip, it will fly on yours.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>🍊 The Story Behind the Name</h3>
      <p>Originally named <b>"X"</b> after the X11 compositor—though we're moving away from X11 due to memory leaks. The codename shifted from <i>Orange</i> to <i>Lemon</i> because citrus is citrus.</p>
    </td>
    <td width="50%" valign="top">
      <h3>🛠️ Future Roadmap</h3>
      <p>Next big milestone on the radar: attempting a <b>Linux From Scratch (LFS)</b> build—once we mentally prepare for the pain.</p>
    </td>
  </tr>
</table>
